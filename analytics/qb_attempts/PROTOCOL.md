# Five-year QB passing attempts protocol

Research target is total regular-season passing attempts credited in nflverse play-by-play during the draft season and four following years. Cohorts are 2001–2018 officially drafted QBs, using `position = QB` in the repo's nflverse draft table and predicting at the end of each draft. This selected population excludes undrafted, supplemental, and position-reclassified prospects outside these source rows. The candidate uses realized draft round. Five-year evaluation uses origins 2011–2018. At each origin train on 2001 or later cohorts whose fifth season ended strictly before the draft year. Historical features are limited to draft identifiers and round. The 2018 forecast uses only donor labels ending by 2017.

Require season-level regular-season game-ID equality between play-by-play attempts and the repo schedule's completed games. Fail on duplicate play IDs within eligible attempts. Start from regular-season `pass_attempt = 1`, retaining play type pass or spike, excluding sacks and conversion attempts. Include spikes if credited by those fields. Count by GSIS and record unavailable passer IDs. Join to drafted QB identity on the draft table's paired GSIS/PFR identifiers. Require both IDs, canonical GSIS format, and unique mappings in the cohort universe. Do not use name matches. In a complete source, the target is zero recorded credited attempts when an unambiguous ID has no rows. Null or ambiguous identity is unknown and excluded from scoring. Record counts and the upper-bound number of unattributed attempts in each cohort's five-season window. Exact attempt counts are retained across changes in scheduled games per season.

Benchmark is the empirical five-season attempts distribution across all eligible donors. Candidate is the corresponding distribution for the prospect's round bin using groups round 1, rounds 2–3, and rounds 4–7. If fewer than five donors exist in the bin, use the benchmark. No tuning. Primary score is paired difference in CRPS (candidate minus benchmark) in attempt units. Also report median-forecast absolute error, 80% interval coverage, below/above support count, and cohort results. A 5,000-draw percentile bootstrap resamples players within origin, fixed seed 2018. It conditions on the historical cohorts and fitted forecasts. Require the upper endpoint of the 95% interval below zero and improvement in at least six of eight origins to advance as post-draft attempts research. Make no snaps conversion or runtime change.
