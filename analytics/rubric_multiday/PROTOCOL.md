# Frozen multi-day rubric sensitivity protocol

Freeze this protocol before running or inspecting any policy outcomes. The date frame is the six consecutive closed UTC dates November 1–6, 2026. Use all dates in the frame. Generate configurations through the repo's authoritative GET handler with a fixed noon UTC clock and an isolated SQLite database initialized with the D1 migration. Save only the config rows from this isolated database. Replay the persisted seed, salt, franchise, scenario, and version pins. This samples the actual daily assignment mechanism without reconstructing production users or challenge seeds. Fail if fewer than three franchises or three scenario classes are represented. Do not substitute dates. Fixture generation and policy simulation are separate commands.

Compare exactly four policies per date using only the visible draft-day DTO for scripted player choices. The engine CPU utility fallback is a benchmark with no scouting. The three scripted policies spend up to 12 scouting points on distinct shared reports, early in the draft. Rank candidates for scouting by broad-position bonus then by public alias. Deduplicate reports by the shared unlocked state in the next official disclosure. After scouting, score candidates by visible shared probability midpoint (zero when hidden or unavailable), plus the same broad-position bonus, and break ties by ascending public alias. Put the first 100 on each board. Bonuses are zero for the general policy, 0.25 at QB for the QB policy, and 0.20 at OL/DL for the line policy. Use the runtime auto-completion for all policies. No active user trade strategy is included. If any variant cannot run, fail the audit.

Pair policies on all 256 replica indices and use the runtime's exact simulation, compaction, expanded shared-report coverage, score component and scoring functions. Check independent weighted-sum agreement with the runtime decision score for all policies. Use the runtime leaderboard for every integer ranking and cross-check competition ranks independently. Baseline ties share ranks. A leader changes when the full first-place set changes. Spearman uses average tied ranks and is undefined for a constant ranking. Raw precision is diagnostic only.

Multiply one of the five runtime weights by 0.5 or 1.5, then renormalize all weights, leaving the simulated draft and component scores fixed. These predeclared scenarios are design perturbations. Report changed-leader counts by date and perturbation, minimum defined Spearman, undefined comparisons, tied baseline winners, invariant components by date, and unrounded diagnostic results. The primary comparison unit is date by perturbation, with 10 perturbations per date. Treat counts as descriptive since dates were selected by a fixed convenience frame and perturbations reuse the same drafts and outcomes. Do not calculate binomial intervals or population p-values.

As a finite-ensemble check, rerun the same comparisons independently on the first and second contiguous 128-index halves using the official score reducer, over draws already computed. Contrast both default leader sets and perturbation leader-change calls with the full ensemble. These checks describe sensitivity to the number of simulation draws. They do not estimate broader model error, leaderboard fairness, or causal GM skill.
