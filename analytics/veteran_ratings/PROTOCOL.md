# Veteran Madden ratings hindcast

Freeze before model fitting or inspecting outcome performance. Evaluate whether a dated overall rating adds incremental information about **next regular-season participation** for prior-season NFL offense and defense veterans.

- Prediction origins are the starts of the 2023 and 2024 NFL drafts. Use the prior Madden season's Super Bowl snapshot, exactly as dated in the archive. The 2024 origin is primary. Its ratings file was published before the draft and fitting can use 2022–23 outcomes and both available archive files. For the 2023 origin, the held-out ratings were dated before the draft but the dated GitHub copy was published shortly after the draft. Treat this evaluation as a retrospective sensitivity only. The 2022 data are a training cohort.
- Include anyone with at least one offense or defense snap in the preceding regular season, who can be matched unambiguously to a valid overall rating at that snapshot by normalized name. Match only prior-season PFR identities, reject duplicates on either side and handle movement across teams without using future team information. Use Madden's prior-year rookie rows only when those players already logged regular-season NFL snaps and thus are veterans at the prediction origin. Never join an incoming draft class to its future rookie ratings.
- For each player, determine position from the previous season's most recent NFL snap appearance. The baseline uses position, preceding two seasons' log of primary-side snap counts (larger of total offense and total defense), and preceding two seasons' games played. If a player has no observed participation in the second prior season, counts are zero. The augmented model changes only by adding Madden overall rating. Fit both logistic models on the same rows with fixed L2 regularization, C=1, train-only scaling and one-hot position encoding. Compare on the same matched held-out rows.
- The binary outcome is at least 500 next-season regular-season primary-side snaps. A prior player with no next-season snap record has zero observed snaps. This captures availability and opportunity as well as ability. Use all NFL teams and regular-season weeks. Include QB only as a position for descriptive breakdown, with no QB model selection.
- Report paired differences in Brier score and log loss (augmented minus baseline), 95% player-resampled percentile intervals (2,000 replications, fixed seed), AUC for context, matched coverage and each exclusion count. Interval scope is the evaluation season's sampled players and ignores season-level dependence. The primary screen requires improved Brier and log loss with both intervals below zero. Even if the screen passes, one primary season is insufficient for release. Any application to team needs, point forecasts, or rookie drafting requires separate evaluation against the corresponding outcome.
- Ship only aggregate results, reproducible code and input hashes. Rating downloads are external inputs. Do not distribute EA's raw values or add the data to the live app.
