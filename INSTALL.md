# Install REDRAFT research alpha

This package contains the application, versioned historical scenarios, analytical artifacts and tests. Supported years are listed by the running app and coverage manifest. Full scientific and production release criteria remain incomplete.

## Requirements

Node.js 24; pnpm 11.25.0; Python 3.11+ for analytics; network access to dependency registries. Use a trusted Node/pnpm installation. Do not send API keys or passwords in chat.

```sh
node scripts/setup.mjs
# Optional isolated analytical environment:
node scripts/setup.mjs --python
```

The setup uses the frozen lockfile and runs real domain tests. It stops on any failure. It does not modify global Python packages, overwrite an existing virtual environment, publish a server or create accounts. Windows/macOS behavior is not verified by the Linux execution.

## Tests

```sh
node tests/run.mjs
python3 tests/warehouse_test.py
node node_modules/typescript/bin/tsc --noEmit
```

Research ingestion needs source access. Activate .venv before Python research commands, then follow README.md and SOURCE_REGISTRY.md. Do not interpret missing raw files as zero data. The full gauntlet requires reacquiring source inputs and can legitimately exit2when statistical gates fail.

## Play locally

The checkout can run without a Cloudflare account. The app uses Wrangler's local D1 emulator and the Sites middleware's loopback-only sign-in fixture. Keep the server bound to loopback; `dev:local` does this for you. The fixture shares saved drafts within this local database and is not a real account.

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run db:local-init
pnpm run dev:local
```

Open `http://127.0.0.1:5173/signin-with-chatgpt?return_to=%2F` first, then continue to the local URL printed by Vite. Local D1 state is stored under `.wrangler/state` and is ignored by Git. `db:local-init` always uses `--local`, the checked-in runtime migration, and the local persistence path; it skips initialization when the runtime tables already exist. To reset local saves, stop the server and remove `.wrangler/state` before initializing again.

The local sign-in sets an HttpOnly cookie; the Vite Sites middleware strips caller-supplied identity headers and injects its fixture only for loopback requests. The game API still requires authenticated identity headers, including in production.

For the regular Vite development command, use `pnpm run dev`; the Sites middleware provides the same loopback-only sign-in flow. Read DEPLOYMENT.md for hosted D1 and platform identity.

The D1 config generated by the build uses a placeholder database ID and Wrangler's local emulator. This is not a remote connection and no credential is required.

## Repository and source download

The source is maintained at https://github.com/jviola1019/redraft . Use GitHub's **Code → Download ZIP** or clone the repository. The archive is installable source, not a prebuilt desktop application. Dependency installation and the build are required.

Raw downloads, installed dependencies, local saves and credentials are excluded. Existing remote code and installation instructions are part of the same release checkpoint; historical reports remain labeled with their execution dates.

## Browser and HTTP verification

After build and local database initialization, run `node tests/local-http.mjs` for real local sign-in, API, server-rendering and save/reload checks. Run `pnpm exec playwright install --with-deps chromium webkit` and `pnpm run test:browser` where browser execution is permitted. `REDRAFT_BROWSER=webkit pnpm run test:browser` checks WebKit with desktop and phone emulation. These tests do not substitute for a physical iPhone.
