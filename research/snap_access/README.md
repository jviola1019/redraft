## Public 2012 archive

The [nflscraPy SnapCounts release](https://github.com/blnkpagelabs/nflscraPy/releases/tag/SnapCounts) has a 2012 player-game CSV and its release metadata contains no 2011 CSV. The README documents PFR provenance, and the CSV contains PFR player and box-score links. The [MIT text](https://github.com/blnkpagelabs/nflscraPy/blob/main/LICENSE) explicitly grants rights for the software and associated documentation. No separate upstream grant for the historical release table or identified NFL data appeared in the repository or release materials reviewed. Public AWS/GitHub delivery and the availability of a page export do not establish the requested training and deployment rights. Review any provider reply for the precise data/version and use before proceeding. [Release metadata](https://api.github.com/repos/blnkpagelabs/nflscraPy/releases/tags/SnapCounts) · [Project README](https://github.com/blnkpagelabs/nflscraPy)

Read-only verification of the public asset in memory found 23,830 rows across 267 games. Reconciliation to the local completed-game schedule found 256 of 256 regular-season games, 512 of 512 team-games and 11 postseason games. The archive uses modern or different abbreviations on four franchises in this season. Normalize `LA → STL`, `JAC → JAX`, `LV → OAK` and `LAC → SD` before checking membership. The 22,856 regular-season rows include 22,851 unique identified player/team/game records and five rows labeled linebacker with no player name or ID. Nine of the 14 2012 combine QB rows with existing IDs have positive 2012 observations. That leaves five existing IDs without positive records, plus five combine rows without IDs. Game coverage by itself cannot settle those identities or supply verified zero seasons. [Audit receipt](VALIDATION.txt) · [Reproduction script](audit_public_fixtures.py)

I found no separately licensed first-party 2011 or 2012 player-game snap corpus covering all three phases. nflverse publishes a CC BY 4.0 distribution, with an empty 2012 snap file and a different play-participation dataset starting in 2016. Standard historical play-by-play cannot recover uncredited participants or verified zeros. A contemporaneous PFF report distinguishes its own charting from the NFL gamebook numbers and describes counting penalty plays in a 2012 example. An academic Football Outsiders study describes historical positional groupings, which are insufficient to reconstruct who played each snap. [nflverse licensing](https://github.com/nflverse#licensing) · [Snap loader](https://nflreadr.nflverse.com/reference/load_snap_counts.html) · [Participation loader](https://nflreadr.nflverse.com/reference/load_participation.html) · [PFF comparison](https://www.pff.com/news/snap-counts-a-deeper-look) · [Stanford project report](https://cs229.stanford.edu/proj2016/report/LeeChenLakshman-PredictingOffensivePlayTypesintheNFL-report.pdf)
