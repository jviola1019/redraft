## Governance and interpretation

Raw HTML/PDF/CSV files are gitignored private snapshots. Reproduction fetches exact URLs and records their digests. If an upstream file changes, it is a new dataset version requiring review; an existing cached raw file is not silently overwritten. An unfetched source is not recorded as successfully ingested. No fuzzy entity matching is used: every non-ID match has an explicit alias and school constraint in the audit output.

The 2018 playable catalog contains only independently verified combine participants. The 39 additional actual draftees are kept in the canonical catalog solely for the actual-history/simulated-baseline reference and have `playable:false`. This is an incomplete eligible pool, but it avoids choosing playable non-combine prospects because of future draft success. The asymmetry between baseline and playable pools is a documented modeling limitation.

Null means a source did not supply a value. The pipeline cannot distinguish unmeasured from unreported for every test; it does not invent this distinction or replace null with zero. A source with no rows, such as the 2012 snap file, is unavailable data rather than evidence of zero participation.

## November 4 prior-season context extension

Fresh source verification and detailed field interpretation are recorded in [TEAM_CONTEXT.md](TEAM_CONTEXT.md). Additional releases are the [2017 depth chart](https://github.com/nflverse/nflverse-data/releases/download/depth_charts/depth_charts_2017.csv), [roster dictionary](https://raw.githubusercontent.com/nflverse/nflreadr/main/data-raw/dictionary_rosters.csv), and [depth-chart dictionary](https://raw.githubusercontent.com/nflverse/nflreadr/main/data-raw/dictionary_depth_charts.csv). Access is public, with no key or cost. The depth chart has 36,620 rows and 32 teams; its unit labels do not encode schemes, and the current dictionary uses a newer schema. Original row publication timestamps are unavailable. The depth release follows the nflverse release licensing declaration; documentation is consulted for semantics without republishing its prose.

The annual 2017 roster is now used only for audited identity links and explicitly labeled last-observed seasonal records attached to 2017 contributors. It still does not establish April 2018 roster membership. A separate manifest `data/clean/team_context_source_manifest.json` records fresh retrieval provenance and the exact artifact hash. `data/clean/source_manifest.json` was refreshed for the full raw corpus; earlier November 2 dates in this registry describe the original research checkpoint, not a claim that current downloads occurred then.
