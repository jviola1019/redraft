## Quarterback experiment protocol

Retain the current three-positive-donor limitation as a failure. Do not fix it by widening intervals until they pass. Compare: position empirical baseline; shrinkage toward a pre-cutoff league prior; regularized two-part model (participation then conditional snaps). Sample complete trajectories or use correlated latent role/availability paths. Bootstrap by draft cohort, not player-season rows. Fit imputation/calibration inside each temporal training partition. For each origin, only outcomes genuinely observable before that draft are eligible. Keep untouched later cohorts separate from repeatedly inspected2018results. Specialists require their own targets. QB model selection requires improvement over the baseline with uncertainty and subgroup results; otherwise retain the simpler model and label unsupported forecasts.

## Forecast and game policy

Generated future rookies are hypothetical players, never fabricated real prospects. Use empirically estimated position/round distributions from pre-cutoff classes, keyed seeds, alternate standings and conserved pick ownership. Separate physical ability, opportunity and measured production. Full veteran membership starts from dated records; unobserved offseason continuity must be disclosed. Contracts, schemes and injuries may not be invented. Any approximation blocks the corresponding realism claim.

## Prompt/workstream contracts

Use bounded assignments, not a repeated command to 'pass everything'. Each assignment supplies: exact input files/hashes, historical cutoff, target/output schema, allowed writes, prohibited leakage, fixed seed matrix and stop condition.

Engine prompt: 'Implement the stated rule using pure functions and keyed random streams. Provide independently computed fixtures and invariant tests; distinguish NFL rules from assumptions.'
QA prompt: 'Try to falsify release claims. Check stale artifacts, temporal leakage, silent zeros, duplicate players/assets, improbable scoring tails, seed coupling and hidden identity exposure. Retain failing seeds; rerun only after an identified correction.'
Integration prompt: 'Record changed contracts and exact source commit. Execute the fixed suite once per frozen candidate. Return pass/fail/unsupported separately. Publish only claims supported by the resulting artifacts.'

## Release decision

Full release requires every original acceptance family, not merely a green build. No available data can directly validate a hypothetical alternate history as causal truth. Validate predictive distributions on observed histories and test structural correctness separately. Expected outcomes and model uncertainty must remain labeled. Repeated testing is not new independent evidence.
